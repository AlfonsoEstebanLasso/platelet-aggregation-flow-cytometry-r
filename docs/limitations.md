# Known limitations of the 2021 code

This page lists the defects known in the five legacy scripts published in
`legacy/`. The scripts are published as delivered and cleaned (see
`docs/cleaning.md`): none of the defects below has been corrected in the code,
because the results of the study were produced with the scripts as they were.
All line numbers refer to the cleaned files in `legacy/`, which carry a
14-line provenance header; the line of the delivered file is therefore the
cleaned line minus 14. The scripts were not executed while preparing this
release, since the private input tables are not available outside the study.

The last column of each table states the fix planned for v1.0, whose roadmap
is: refactored functions, exported figures and tables, and a synthetic example
dataset.

## Closing note

The results of the study were produced with these scripts as they were, in
interactive R sessions during 2021. The defects listed here are documented,
not corrected, so that the published code matches the delivered code apart
from the cleaning transformations recorded in `docs/cleaning.md`. Corrections
belong to the refactored version planned for v1.0 and will be reported as
differences with respect to the legacy scripts, never silently applied to
them.
